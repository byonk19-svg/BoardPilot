# Historical baseline snapshot

This folder preserves representative metadata and CSV evidence from the earlier
CLI baseline build. It is a partial snapshot, not a complete CAD artifact set.
Its manifest describes the original full output, which remained in local app data.

Use `../reference-bookcase/project.zip` for the complete 18/6 mm sample or
`../authored-bookcase/project.zip` for the complete authored-method sample. Both
folders contain their full saved geometry, documents, stock outputs and package.
